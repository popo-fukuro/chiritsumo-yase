# ちりも積もれば痩せとなる

毎日3つの小さなミッションから1つ選んで、やったら「できた」を押すだけ。「痩せるアプリ」ではなく、**3日坊主を卒業するアプリ**です。最初のゴールは、7日続けること。登録もインストールもいりません。

👉 **使う：https://popo-fukuro.github.io/chiritsumo-yase/** （GitHub Pages で公開したあと）

## 使い方（1日10秒）
1. アプリを開く
2. 今日のミッション3つから、1つ選ぶ（「食後に5分だけ歩く」くらいの小ささ）
3. やる
4. 「できた！」を押す → 連続日数・合計日数が増えて、ちりが1粒積もります
5. 体重を記録したければ入れる（スキップしてOK）

- 選んだあとでも、「できた」を押す前なら選び直せます
- 押しまちがえたら「取り消す」で戻せます
- 「きろく」でカレンダーと、直近14日の体重グラフが見られます
- スマホでは「ホーム画面に追加」して使うのがおすすめです（iPhone: Safari の共有ボタン →「ホーム画面に追加」）

## しくみ
- **ミッションは毎日3つ**。「うごく」「のむ・たべる」「かえる・やめる」から1つずつ出ます（設定でカテゴリをオフにできます）
- **連続1〜7日目は、いちばん軽いミッションだけ**。8日目から少しだけ、15日目からもう一段だけ重くなります。3つの重さはいつも揃えています
- **1日空いても合計日数は減りません**。お休みした次の日は、超かんたんな「おかえりの日」になります（水を1杯飲む、など）
- お祝いは 3日（いちばん大きく）→ 7日 → 14日 → 30日 →（60日・100日…）
- ミッションの一覧は [`missions.js`](missions.js) にあります。ここを書きかえると、出てくるミッションを増やしたり直したりできます

## データについて
入力したデータは、あなたの端末（ブラウザ）の中だけに保存されます。どこにも送信されません。

- 別の端末や別のブラウザとは、記録は共有されません
- 記録の書き出し（バックアップ）の機能はありません
- ページを置いている GitHub が、アクセスの記録（IPアドレスなど）を保存します

## ご注意
- このアプリは体重の記録と習慣づくりのための道具で、医療・ダイエットの助言をするものではありません。体調や減量のことは、医師などの専門家にご相談ください
- 共用の端末で使うと、記録が他の人にも見えます
- 記録はお使いのブラウザの中だけに保存されます。ブラウザのデータ削除や端末の変更、長いあいだ開かなかった場合などに消えることがあります
- iPhone ではプッシュ通知は使えません（このアプリには通知の機能はありません）
- このアプリは無保証で提供しており、記録が消えたことなどによる損害には責任を負えません

## 開発メモ

### ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面（ホーム / きろく / せってい） |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | 動き（ミッションの出し方、連続日数、カレンダー、体重グラフ） |
| `missions.js` | ミッションの一覧 |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | オフラインでも開けるようにするためのもの |

ビルドは不要です。静的なファイルだけで動きます。

### 手元で動かす
```sh
cd chiritsumo-yase
python3 -m http.server 8000
```
ブラウザで http://localhost:8000/ を開きます。スマホで見た目を確かめるときは、パソコンのブラウザの開発者ツールでスマホ表示にするのが手軽です。

日をまたいだ動き（連続日数、8日目からの難易度、おかえりの日など）を確かめたいときは、パソコンの日付を変えるか、別のブラウザのプロフィールで試してください。記録を消したいときは「せってい」→「すべての記録を削除する」。

### GitHub Pages で公開する
1. GitHub のリポジトリ `chiritsumo-yase` を開く
2. **Settings** → 左の **Pages**
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch を **main**、フォルダを **/ (root)** にして **Save**
5. 1〜2分待つと https://popo-fukuro.github.io/chiritsumo-yase/ で開けるようになります

ファイルを更新したら、main に push するだけで公開ページも更新されます（反映まで数分かかることがあります。ホーム画面のアプリは、一度閉じて開き直すと新しい版になります）。
